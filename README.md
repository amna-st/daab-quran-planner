# دَأْب | بلانر حفظ القرآن الكريم

تطبيق ويب عربي RTL قابل للتثبيت (PWA)، لتنظيم الحفظ والمراجعة والتسميع واليوميات والتقارير. الاسم الجديد «دَأْب» يعني المواظبة والمداومة على العمل.

## المميزات
- حساب مستقل لكل مستخدمة بالبريد وكلمة المرور عبر Supabase Auth.
- مزامنة بيانات الحفظ والمراجعة والتسميع واليوميات بين الأجهزة.
- خريطة السور الـ114 والأجزاء الـ30 (أرقام الصفحات تقريبية لمصحف المدينة 604 صفحات).
- خطة ختم الحفظ بحسب تاريخ البداية والموعد المستهدف والصفحات اليومية.
- جدول مراجعة متباعدة مقترح بعد 1 و3 و7 و14 يوماً.
- دفتر تسميع وتسجيل الأخطاء ودرجة الإتقان.
- يوميات وتأملات خاصة وتقارير شهرية ونسخ احتياطي.
- مساعد رجوع بعد الانقطاع يقترح تخفيف الورد بدلاً من مضاعفته.
- شارات إنجاز شخصية.
- تحديات جماعية ومجتمع مشاركات نصية عند ربط Supabase.
- 4 ثيمات لونية.
- تذكير محلي بإشعار المتصفح عندما يكون التطبيق مفتوحاً/نشطاً.

## تنبيه بخصوص الحسابات والخصوصية
كل سجلات الحفظ واليوميات والتسميع مخزنة في جدول `daab_data` بسياسات RLS تمنع أي مستخدمة من قراءة بيانات غيرها. جداول التحديات والمشاركات منفصلة؛ منشورات المجتمع نصية عامة للمستخدمات المسجلات، لذلك لا تكتبي فيها معلومات خاصة. لا توجد رسائل خاصة أو رفع ملفات في المجتمع.

## إعداد Supabase (مطلوب مرة واحدة)
1. أنشئي مشروعاً مجانياً في https://supabase.com.
2. افتحي SQL Editor وشغّلي محتوى `supabase-schema.sql` كاملاً.
3. من Project Settings > API انسخي Project URL و anon/public key.
4. افتحي `config.js` واستبدلي `YOUR_SUPABASE_PROJECT_URL` و`YOUR_SUPABASE_ANON_PUBLIC_KEY` بالقيم الحقيقية.
5. من Authentication > URL Configuration أضيفي رابط Netlify إلى Site URL و Redirect URLs.
6. من Authentication > Providers فعّلي Email. إعداد تأكيد البريد حسب رغبتك وسياسة الأمان.
7. لا تضعي `service_role` key في الموقع أبداً.

## النشر عبر GitHub وNetlify
1. أنشئي مستودعاً جديداً باسم `daab-quran-planner`.
2. ارفعي محتويات هذا المجلد إلى جذر المستودع.
3. في Netlify اختاري Add new project > Import an existing project > GitHub.
4. اختاري المستودع، اتركي Build command فارغاً، واجعلي Publish directory = `.` ثم Deploy.
5. أضيفي رابط Netlify في إعدادات Supabase كما في الأعلى.
6. افتحي رابط الموقع من الهاتف واختاري Add to Home Screen / Install app.

## التذكيرات
التذكير الحالي يعتمد على Notification API ويفحص الوقت كل دقيقة أثناء تشغيل التطبيق. المتصفحات والهواتف قد توقف الفحص عند إغلاق التطبيق؛ الإشعارات المضمونة في الخلفية تحتاج Web Push مع خادم/وظيفة مجدولة ومفاتيح VAPID، ولم ندّعِ أن هذا الجزء يعمل بعد.

## التجربة
يمكن تجربة التطبيق محلياً دون حساب. بيانات التجربة تبقى على نفس المتصفح ولا تنتقل للأجهزة ولا تدخل المجتمع المشترك.

## ملاحظات
- لا يحتوي التطبيق على نص المصحف أو صوت التلاوة؛ هو منظم للمتابعة والتخطيط.
- صفحات السور تقريبية بحسب مصحف المدينة، وقد تختلف الطبعات.
- التحديات تدعم الإنشاء والانضمام وتسجيل الصفحات المنجزة لكل مستخدمة داخل التحدي، مع عرض مجموع إنجازها الشخصي.
